TASK 2 — ADD EMA CROSSOVER STRATEGY:

Create a new class EmaCrossoverStrategy : IStrategy

This strategy must support ALL of the following config parameters
(expose each as a configurable field, not hardcoded):

- FastEma (int)
- SlowEma (int)
- MiddleEma (int) — only used when UseTripleEma = true

- Timeframe: enum { Intraday, Swing, Both }

- FilterType: enum { RSI, Volume, SupportResistance, PriceAction }

RSI filter config (active when FilterType = RSI):
- RsiPeriod (int, default 14)
- RsiMidline (int, default 50)
- RsiOverbought (int, default 70)
- RsiOversold (int, default 30)

Volume filter config (active when FilterType = Volume):
- VolumeAvgPeriod (int, default 20)
- VolumeMultiplier (decimal, default 1.5)

Support & Resistance filter config (active when FilterType = SupportResistance):
- SRLookbackPeriod (int, default 20)
- SRBuffer (decimal, default 0.5)

Price Action filter config (active when FilterType = PriceAction):
- AllowedPatterns: multi-select from [ Engulfing, Hammer, Doji, MorningStar ]
- CandleLookback (int, default 1)

TRIPLE EMA MODE:
- UseTripleEma (bool, default false)
- When enabled: entry only when FastEma > MiddleEma > SlowEma (long)
  or FastEma < MiddleEma < SlowEma (short)

TRADE MANAGEMENT:
- StopLossType: enum { FixedPercent, BelowEma, AtrBased }
- StopLossValue (decimal)
- AtrPeriod (int, default 14) — used when StopLossType = AtrBased
- TargetRRR (decimal, default 2.0)
- MaxHoldingPeriods (int)

DIRECTION:
- TradeDirection: enum { LongOnly, ShortOnly, Both }

---

STRATEGY LOGIC (implement exactly as described):

LONG ENTRY:
1. FastEma crosses above SlowEma on current candle
2. If UseTripleEma: FastEma > MiddleEma > SlowEma must all be stacked
3. Apply selected FilterType check:
   - RSI: RSI > RsiMidline AND RSI < RsiOverbought
   - Volume: current candle volume > (VolumeAvgPeriod average × VolumeMultiplier)
   - SupportResistance: price is within SRBuffer% of a identified support
     level from the last SRLookbackPeriod candles
   - PriceAction: one of AllowedPatterns detected within CandleLookback
     candles before entry
4. All conditions pass → enter Long on next candle open

SHORT ENTRY:
1. FastEma crosses below SlowEma
2. If UseTripleEma: FastEma < MiddleEma < SlowEma stacked bearishly
3. Apply selected FilterType check (inverted):
   - RSI: RSI < RsiMidline AND RSI > RsiOversold
   - Volume: same volume condition (volume spike confirms move)
   - SupportResistance: price is within SRBuffer% of identified resistance
   - PriceAction: bearish pattern detected within CandleLookback candles
4. All conditions pass → enter Short on next candle open

EXIT:
- SL hit → exit immediately on that candle
- Target hit (entry ± StopLoss × TargetRRR) → exit
- MaxHoldingPeriods exceeded → exit at close of that candle
- Opposite crossover signal → exit current trade

STOP LOSS CALCULATION:
- FixedPercent: SL = entry price ± StopLossValue%
- BelowEma: SL = SlowEma value at entry candle (long: below, short: above)
- AtrBased: SL = entry price ± (ATR(AtrPeriod) × StopLossValue)
